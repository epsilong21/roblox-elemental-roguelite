# Test Plan

Antes de cerrar un sistema probar cuando aplique:

- un jugador
- varios jugadores
- cliente/servidor
- muerte y respawn
- reconexión
- inputs inválidos
- latencia
- PC
- móvil
- distintas resoluciones
- rendimiento bajo carga

## Reporte mínimo por tarea

- Task ID
- Build/commit
- Caso probado
- Resultado esperado
- Resultado real
- PASS / FAIL
- Evidencia o notas
