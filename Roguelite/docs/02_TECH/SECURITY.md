# Seguridad

Asumir cliente comprometido.

Validar en servidor:
- tipos
- rangos
- distancias
- estados
- frecuencia
- cooldowns
- propiedad
- requisitos
- objetivos

Nunca aceptar desde cliente:
- daño final
- monedas finales
- recompensas concedidas
- estado de invulnerabilidad
- autoridad de muerte
- progreso persistente
