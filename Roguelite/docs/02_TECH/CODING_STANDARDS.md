# Coding Standards

- Luau moderno.
- Nombres claros.
- Tipado cuando mejore mantenibilidad.
- No globals innecesarias.
- Preferir módulos pequeños y cohesivos.
- Separar configuración de lógica.
- Evitar ciclos/eventos que queden vivos tras respawn o destrucción.
- Validar referencias antes de usarlas.
- No capturar errores silenciosamente.
- Evitar dependencias externas salvo justificación aprobada.
- No usar APIs obsoletas.
